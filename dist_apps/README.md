# Panduan Penggunaan & Instalasi Aplikasi PaceNet Multiplatform

Folder ini berisi file aplikasi siap pakai untuk **Android Smartphone / Tablet** dan **Windows Desktop**.

---

## 1. Aplikasi Windows Desktop (`PaceNetPro.exe`)

Aplikasi desktop native untuk komputer kasir, operator loket, dan tim NOC.

### Cara Menggunakan:
1. **Opsi Cepat (Folder Langsung)**:
   - Masuk ke folder `PaceNet-Windows-Desktop`
   - Klik ganda pada `PaceNetPro.exe`
   - Anda dapat membuat shortcut ke Desktop dengan cara: **Klik kanan `PaceNetPro.exe` > Send to > Desktop (create shortcut)**.
2. **Opsi Portabel (.zip)**:
   - Ekstrak file `PaceNet-Windows-Desktop.zip` ke komputer manapun yang menggunakan Windows 10 atau Windows 11.
   - Buka file `PaceNetPro.exe`.

### Fitur Unggulan Desktop:
- **Akselerasi Hardware Edge WebView2**: Sangat cepat, hemat RAM, dan tidak membebani sistem.
- **Multi-Server Connection**: Pilih langsung antara **VPS Utama (`hy0045.my.id`)**, **VPS Backup (`hi1271.my.id`)**, atau **Custom Local IP**.
- **Mode Fullscreen / Kiosk**: Tekan tombol layar penuh di kanan atas untuk menyembunyikan navigasi saat dipakai di meja kasir.
- **Dukungan Cetak Langsung**: Mendukung pencetakan voucher layout F4/A4 maupun printer kasir thermal (POS 58mm/80mm).

---

## 2. Aplikasi Android (`PaceNet-Mobile.apk`)

Aplikasi mobile untuk smartphone dan tablet Android kasir / agen reseller voucher di lapangan.

### Cara Memasang:
1. Kirim atau salin file `PaceNet-Mobile.apk` ke HP Android (bisa lewat WhatsApp Web, USB, Google Drive, atau download langsung).
2. Di HP Android, buka file `PaceNet-Mobile.apk` lalu pilih **Install / Pasang**.
3. Jika muncul peringatan *"Install unknown apps / Sumber tidak dikenal"*, pilih **Izinkan untuk sumber ini**.
4. Buka aplikasi **PaceNet Pro** dari beranda HP Anda.

### Fitur Unggulan Mobile:
- **Izin Kamera Terintegrasi**: Siap untuk pemindaian Barcode & QR Code voucher.
- **Izin Bluetooth Printer**: Mendukung pencetakan struk ke printer kasir bluetooth portable.
- **Auto-Remember Server**: Mengingat pilihan server secara otomatis.
- **Tombol Back Pintar**: Menavigasi riwayat halaman sebelum konfirmasi keluar aplikasi.

---

## 3. Instalasi Alternatif: PWA (Progressive Web App)

Pengguna juga dapat memasang aplikasi langsung melalui browser tanpa perlu install file secara manual:
1. Buka browser **Google Chrome** atau **Microsoft Edge**.
2. Kunjungi alamat: `https://hy0045.my.id/app/`
3. Klik ikon **"Install PaceNet Pro"** di ujung bilah alamat URL (Address Bar) atau menu titik tiga > **"Install / Pasang Aplikasi"**.
4. Aplikasi akan terpasang di desktop atau layar beranda HP Anda secara instan.
